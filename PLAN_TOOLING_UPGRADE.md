## Shared invariants, safety and interfaces
1. **Snapshot safety:** a PASS is bound to immutable, content-addressed source + relevant toolchain/environment/spec/adapter inputs. Real changes during capture must cause bounded retry then explicit BLOCKED, not silent PASS. Diagnose changes without exposing secret contents or unrestricted paths; do not scan arbitrary ignored build artifacts as source inputs.
2. **Evidence distinction:** PASS, FAIL, SKIPPED, ERROR-BLOCKED; host unit, device compile/link, Simulator runtime, physical device runtime are separate. No upgrading a skipped runtime gate to PASS.
3. **Cross-repo compatibility:** release manifest SHA256/source SHA/host triple/schema support must match installed binary. Positive and negative fixture behavior must pass before archive promotion. Maintain rollback to last verified release.
4. **Schema safety:** `frameworks: []` is valid for system-library-only bridges; nonempty framework names still validated and only requested frameworks linked. No spurious framework or unsafe linker flag.
5. **Determinism:** fixed test inputs, fake clock/filesystem or mutation hooks where needed, stable ordering/serialization, per-commit evidence provenance. No `sleep`-based race tests, real service dependencies, or device assertions without device execution.
6. **Boundaries:** generic validator/builder work belongs to tooling repo; framework-specific specs, capability audits, CI/install/docs and bug-report closure belong to framework repo. Preserve current unrelated Rust API implementation and manual CI dispatch policy.

## Cross-workstream acceptance tests
- Stable tracked+explicit untracked source capture succeeds identically in primary and detached worktrees; intentionally modified file during capture gives deterministic changed-input diagnostics and does not PASS. Repeat with ignored outputs, symlinks, deleted/renamed paths, concurrent writers and malformed paths.
- Builder accepts `frameworks: []` and builds `os/log.h` C bridge with only system libraries. Nonempty frameworks continue to emit precisely requested linker directives; malformed framework names and missing targets still reject.
- Release installation checks full source SHA/host/archive digest/version/schema, runs `--help`/capability handshake, and rejects downgrade/mismatch. Old release remains recoverable.
- Registered validation selects correct changed-profile graph under changed package exports, feature sets, build scripts, specs and dependencies, conservatively selecting extra profiles for unknown edges.
- Capability consistency audit catches missing package/profile references, duplicate IDs, invalid paths/deployment floors and stale generated files while allowing explicit unsupported/deferred exceptions; outputs deterministic bytes at fixed SDK/toolchain fingerprint.
- Evidence report encodes all forms of proof and skips honestly; output is stable in a fixed snapshot and does not include machine-specific absolute paths/secrets.
- Existing CLI JSON/editor, native builder, report generator, framework host tests, device/simulator compile-link checks remain passing. Real Simulator/device runtime evidence must be reported separately.
