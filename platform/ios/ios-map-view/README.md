# ios-map-view

`ios-map-view` creates a main-thread-bound public `MKMapView`, exposes its borrowed native view for UIKit embedding, gets/sets a finite `MapRegion`, replaces caller-owned marker snapshots, and draws one caller-supplied route path. The host owns layout and hierarchy; MapKit can adjust the requested region to the current view dimensions.

`MKMapView` is an imperative native UIKit view, not SwiftUI or a declarative map framework. `MapAnnotation` holds an application-defined stable id, validated coordinate, and optional borrowed title. `replace_annotations` rejects duplicate ids, reuses native `MKPointAnnotation` objects for ids that persist, updates coordinates and titles, and removes omitted ids. MapKit copies titles. `replace_route` accepts 2 through 4,096 validated coordinates and replaces the one route overlay; `clear_route` removes it without changing annotations. The route style is fixed to `UIColor.blueColor()` at 5 points. The crate does not enable user location, request permission, search, geocode, calculate directions, provide offline maps, or expose a general overlay engine. MapKit owns basemap content and any native network fetch behavior; this crate does not promise map content availability or prove runtime fetching.

`MKMapView.delegate` is a weak singleton slot. While a route is active, `IosMapView` owns this slot and retains its narrow `MKMapViewDelegate` object. Route activation fails with `MapRouteError::DelegateSlotOccupied` when a host delegate is already set. The host must not replace the native delegate while the route is active. If it does, a later route replacement fails; `clear_route` and drop still remove only the owned route and preserve the host's replacement delegate. Marker annotations remain independent of this delegate.

The selected `objc2-map-kit 0.3.2` generated `MKMapView` binding is gated behind macOS/AppKit, so this iOS crate defines the public iOS `MKMapView` class and the exact `MKMapViewDelegate` renderer callback ABI with `objc2`. It reuses the generated public region, annotation, polyline, and renderer bindings. MapKit's public route renderer callback is available from iOS 7.0; the map and marker APIs remain available from iOS 3.0 and 4.0. No Swift source is used.
